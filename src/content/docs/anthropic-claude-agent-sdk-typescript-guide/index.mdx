## Notable changes

Most releases track Claude Code and leave the API alone. The ones that matter:

- **0.3.301** — `BUILTIN_TOOL_NAMES` / `LEGACY_TOOL_NAME_ALIASES` exports; per-tool permission policies on SDK MCP servers.
- **0.3.282** — `@anthropic-ai/claude-agent-sdk/core`, a smaller entry point for bundled apps.
- **0.3.280** — `verbatimPrompts`: prompts are delivered literally, with no `@file` expansion or slash commands.
- **0.3.259** — `permissionPrompts: 'none'` for unattended sessions.
- **0.3.257** — `getContextUsage({ detail: 'summary' })`.
- **0.3.223** — `resumeDropsTurn` for safe truncating resume.
- **0.3.142 (breaking)** — `unstable_v2_*` session API removed; MCP servers connect in the background; Task tools replace `TodoWrite`.

Full list: the upstream [CHANGELOG](https://github.com/anthropics/claude-agent-sdk-typescript/blob/main/CHANGELOG.md).

## Minimal example

There is no `Agent` class. `query()` is the entry point; it returns an async generator of typed messages.

```typescript
import { query } from '@anthropic-ai/claude-agent-sdk';

for await (const message of query({
  prompt: 'What is 15 + 27?',
  options: {
    model: '%%model=anthropic-flagship%%',
    systemPrompt: 'You are a helpful assistant.',
  },
})) {
  if (message.type === 'result' && message.subtype === 'success') {
    console.log(message.result);
  }
}
```
