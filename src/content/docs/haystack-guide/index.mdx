**Pipelines first, agents included.** Haystack builds LLM applications from typed components (retrievers, rankers, prompt builders, chat generators) wired into pipelines. The `Agent` component runs a tool-calling loop with state and hooks, and can sit inside a pipeline like anything else.

**Current version: `haystack-ai` %%version=haystack-ai%%** (checked %%versions-checked%%). Python 3.10+.

## What changed in Haystack 3

- **Generators removed.** `OpenAIGenerator`, `AzureOpenAIGenerator` and the Hugging Face text generators are gone; ChatGenerators accept a plain `str` and return `ChatMessage` replies.
- **`ToolInvoker` removed.** Tools are passed to `Agent`; `tool_invoker_kwargs` became `tool_concurrency_limit` and `tool_streaming_callback_passthrough`.
- **`AsyncPipeline` merged into `Pipeline`**, which now has `run`, `run_async`, `run_async_generator` and `stream`.
- **Agent hooks.** `before_run`, `before_llm`, `before_tool`, `after_tool`, `on_exit`, `after_run`; human-in-the-loop confirmation is a `ConfirmationHook` in `haystack.hooks.human_in_the_loop`.
- **Stricter defaults.** Prompt variables are required; tools read `State` only through `inputs_from_state`; `Pipeline.load` uses a module allowlist.
- **Leaner core.** Hugging Face, sentence-transformers, web search, Whisper, OpenAPI, OpenTelemetry and Datadog components moved to integration packages under `haystack_integrations.*`; `haystack-experimental` is no longer installed by default.

## Minimal example

```python
from haystack.components.agents import Agent
from haystack.components.generators.chat import OpenAIChatGenerator
from haystack.dataclasses import ChatMessage
from haystack.tools import tool


@tool
def get_weather(city: str) -> str:
    """Get the current weather for a city."""
    return f"Sunny in {city}"


agent = Agent(
    chat_generator=OpenAIChatGenerator(model="gpt-5-mini"),
    tools=[get_weather],
    system_prompt="You are a helpful assistant.",
)

result = agent.run(messages=[ChatMessage.from_user("What's the weather in Berlin?")])
print(result["last_message"].text)
```
