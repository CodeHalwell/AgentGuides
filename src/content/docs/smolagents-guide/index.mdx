**Agents that act in code.** A `CodeAgent` writes short Python snippets that call your tools, loop and compute; a `ToolCallingAgent` uses ordinary JSON tool calls. The core is small enough to read in an afternoon, which makes it a good first framework and an easy one to debug.

**Current version: `smolagents` %%version=smolagents%%** (checked %%versions-checked%%). Python 3.10+.

<Aside type="caution" title="Generated code runs on your machine by default">
  `CodeAgent`'s default `LocalPythonExecutor` restricts imports but is not a security boundary. Use `executor_type="docker"`, `"e2b"`, `"modal"` or `"blaxel"` for untrusted input.
</Aside>

## Recent releases

- **1.26.0** — Exa added as a `WebSearchTool` engine; the experimental `WasmExecutor` (`executor_type="wasm"`) removed.
- **1.25.0** — Security hardening of remote executors; `allow_pickle` defaults to `False`; documentation now states plainly that `LocalPythonExecutor` is not a sandbox; `huggingface-hub` 1.x supported.
- **1.24.0** — More robust execution timeout for the local executor; `FinalAnswerStep` passed to `step_callbacks`; saved agents that reference the old `HfApiModel` class load as `InferenceClientModel` (the `HfApiModel` import itself has not existed since 1.19.0).

## Minimal example

```python
from smolagents import CodeAgent, InferenceClientModel, tool


@tool
def add_numbers(a: int, b: int) -> int:
    """Add two numbers together.

    Args:
        a: The first number.
        b: The second number.
    """
    return a + b


agent = CodeAgent(tools=[add_numbers], model=InferenceClientModel())   # needs HF_TOKEN
print(agent.run("What is 15 + 27?"))
```
