**Mistral's hosted Agents API.** Stored, versioned agents; server-side conversation state; built-in web search, code interpreter, image generation and document retrieval; MCP connectors; and handoffs between agents.

<Aside type="note" title="Status">
  The Agents and Conversations APIs are beta (`client.beta` in the SDK) and registered MCP connectors are a public preview, so request and response shapes may still change.
</Aside>

## Minimal example

```python
import os
from mistralai.client import Mistral   # import from mistralai.client, not from mistralai

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])

agent = client.beta.agents.create(
    model="%%model=mistral%%",
    name="assistant",
    instructions="You are a helpful assistant. Search the web for anything time-sensitive.",
    tools=[{"type": "web_search"}],
)

response = client.beta.conversations.start(agent_id=agent.id, inputs="What is 15 + 27?")
print(response.outputs[-1].content)

follow_up = client.beta.conversations.append(
    conversation_id=response.conversation_id,
    inputs="Now double it.",
)
print(follow_up.outputs[-1].content)
```
