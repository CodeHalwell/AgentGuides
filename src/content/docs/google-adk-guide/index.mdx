**Google's Agent Development Kit.** Build agents on Gemini with MCP, A2A, multi-agent orchestration, and native GCP IAM. Three language implementations share the same architecture and version independently.

**Current versions** (checked %%versions-checked%%): Python `google-adk` %%version=google-adk%% · Go `google.golang.org/adk` v%%version=google.golang.org/adk%% · TypeScript `@google/adk` %%version=@google/adk%%.

## Install

| Language | Install |
|---|---|
| Python | `pip install google-adk` |
| Go | `go get google.golang.org/adk@v%%version=google.golang.org/adk%%` |
| TypeScript | `npm install @google/adk` |
