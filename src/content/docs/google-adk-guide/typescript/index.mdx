## Minimal example

Agents do not run themselves; a `Runner` drives them. `InMemoryRunner` wires in in-memory services, and `runEphemeral` runs one turn without keeping the session.

```typescript
import {FunctionTool, InMemoryRunner, LlmAgent, isFinalResponse, stringifyContent} from '@google/adk';
import {z} from 'zod';

const getWeather = new FunctionTool({
  name: 'get_weather',
  description: 'Returns the current weather for a city.',
  parameters: z.object({city: z.string().describe('City name')}),
  execute: async ({city}) => ({city, forecast: 'sunny', tempC: 21}),
});

const agent = new LlmAgent({
  name: 'assistant',
  model: 'gemini-2.5-flash',
  instruction: 'You are a helpful assistant. Use get_weather for weather questions.',
  tools: [getWeather],
});

const runner = new InMemoryRunner({agent, appName: 'demo'});

for await (const event of runner.runEphemeral({
  userId: 'u1',
  newMessage: {role: 'user', parts: [{text: 'What is the weather in Leeds?'}]},
})) {
  if (isFinalResponse(event)) {
    console.log(stringifyContent(event));
  }
}
```

Set `GOOGLE_GENAI_API_KEY` (or `GOOGLE_GENAI_USE_VERTEXAI=1` with `GOOGLE_CLOUD_PROJECT` and `GOOGLE_CLOUD_LOCATION`) before running. For multi-turn conversations, create a session with `runner.sessionService.createSession(...)` and call `runner.runAsync({userId, sessionId, newMessage})`.

Export the agent as `rootAgent` from `agent.ts` and you can drive it with the dev tools: `npx @google/adk-devtools run agent.ts` or `npx @google/adk-devtools web`. Always name the package — a bare `npx adk` fetches an unrelated package from the registry.

## What changed in 2.x

The 2.0.0 release (August 2026) introduced graph orchestration and made a few breaking changes:

- `Workflow`, `FunctionNode`, `JoinNode`, `Edge` and `START` arrive; `Workflow` is still marked experimental. A bare `Workflow` can be the root of a `Runner` or `App`.
- `BaseAgent` now extends `BaseNode`, so agents inherit `rerunOnResume`, `retryConfig`, `timeout` and the schema fields. A subclass that declares a field of the same name now collides with the inherited one.
- `SequentialAgent`, `ParallelAgent` and `LoopAgent` log a one-time deprecation warning; they still work.
- `LLMAgentWrapper` is removed — pass an agent to an edge directly.
- `InvocationContext.agent` is optional; inside an agent, use `requireAgent(ctx)`.

Later 2.x releases added `Runner.autoCreateSession` (opt-in), `DebugLoggingPlugin`, `ToolCallIntegrityPlugin`, and broad parity work with the Python kit.
