## Notable changes in the 0.2 series

Most releases only update the bundled Claude Code CLI. The ones that change the API:

- **0.2.170** — `get_session_messages()` returns every branch of parallel tool calls.
- **0.2.166** — typed hook outputs and `SystemInitData`; `SandboxSettings.ignoreViolations` is now a `dict[str, list[str]]`.
- **0.2.158** — `verbatim_prompts` option: prompts are delivered literally, with no `@file` expansion or slash commands.
- **0.2.140** — `ResultError` with structured failure details; `can_use_tool` works with `query()`; `forward_subagent_text`; `mcp` 2.x support.
- **0.2.137** — `ConversationResetMessage`; message `origin`; `resume_session_at` / `resume_drops_turn`.
- **0.2.129** — skill names are validated (breaking for `skills=["*"]`; use `skills="all"`).
- **0.2.126** — `ResultMessage.terminal_reason`; typed `model_usage`.

See the [migration guide](/anthropic-claude-agent-sdk-guide/anthropic_claude_agent_sdk_migration_guide/#part-2--upgrading-within-claude-agent-sdk) for what to change, and the upstream [CHANGELOG](https://github.com/anthropics/claude-agent-sdk-python/blob/main/CHANGELOG.md) for everything else.

## Minimal examples

The SDK has two entry points: `query()` for one-shot tasks and `ClaudeSDKClient` for conversations. There is no `Agent` class.

### One-shot

```python
import asyncio
from claude_agent_sdk import query, ClaudeAgentOptions, ResultMessage

async def main():
    options = ClaudeAgentOptions(
        model="%%model=anthropic-flagship%%",
        system_prompt="You are a helpful assistant.",
    )
    async for message in query(prompt="What is 15 + 27?", options=options):
        if isinstance(message, ResultMessage):
            print(message.result)

asyncio.run(main())
```

### Interactive session

```python
import asyncio
from claude_agent_sdk import ClaudeSDKClient, ClaudeAgentOptions, AssistantMessage, TextBlock

async def main():
    options = ClaudeAgentOptions(system_prompt="You are a helpful assistant.")
    async with ClaudeSDKClient(options=options) as client:
        await client.query("What is 15 + 27?")
        async for message in client.receive_response():
            if isinstance(message, AssistantMessage):
                for block in message.content:
                    if isinstance(block, TextBlock):
                        print(block.text)

asyncio.run(main())
```
