<Aside type="caution" title="Old agent API removed">
  `llama-index-core` 0.13.0 removed the legacy agents (`OpenAIAgent`, `FunctionCallingAgent`, `AgentRunner`, the old `ReActAgent.from_tools(...)` / `.chat()`). Current agents — `FunctionAgent`, `ReActAgent`, `CodeActAgent`, `AgentWorkflow` — live in `llama_index.core.agent.workflow` and are run with `await agent.run(...)`. See the [migration table](./llamaindex_comprehensive_guide/#22-migrating-from-the-legacy-agent-api).

## Recent changes in llama-index-core

Patch releases since the guide was last revised (from the upstream changelog):

- **0.14.25 (September 2026)** — restored streaming for the `compact` and `refine` response modes; native async for `StructuredLLMRerank`; removed the deprecated IPEX integrations; security dependency updates.
- **0.14.24 (August 2026)** — `AgentWorkflow` now honours an agent's `output_cls` / `structured_output_fn`; `Memory` accepts any `AsyncDBChatStore`; async `LLMRerank`; many ingestion and retrieval fixes.
- **0.14.23 (June 2026)** — multimodal query engines and synthesis; a tool-calling mock LLM for tests; `initial_state` is deep-copied per run.
- **0.14.22 (May 2026)** — multimodal synthesis groundwork; ingestion cache and instrumentation fixes.

No breaking API changes in this range. The last breaking releases were 0.13.0 (legacy agents and `QueryPipeline` removed) and 0.14.0 (moved to `llama-index-workflows` 2.x).

## Install, minimal example

```python
import asyncio
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader
from llama_index.core.agent.workflow import FunctionAgent
from llama_index.core.tools import QueryEngineTool
from llama_index.llms.openai import OpenAI

documents = SimpleDirectoryReader("data").load_data()
index = VectorStoreIndex.from_documents(documents)

tool = QueryEngineTool.from_defaults(
    query_engine=index.as_query_engine(),
    name="knowledge_base",
    description="Answer questions about the documents",
)

agent = FunctionAgent(tools=[tool], llm=OpenAI(model="gpt-5-mini"))

async def main():
    response = await agent.run(user_msg="What are the key findings?")
    print(response)

asyncio.run(main())
```
