**The data framework for LLM apps.** LlamaIndex turns documents into indexes that query engines and agents can use: loaders, parsers, vector and graph indexes, query engines, tools, workflows and multi-agent orchestration.

Current release: **`llama-index` %%version=llama-index%%** (Python) with `llama-index-workflows` %%version=llama-index-workflows%% · `llamaindex` %%version=llamaindex%% and `@llamaindex/workflow-core` %%version=@llamaindex/workflow-core%% (TypeScript, final releases — the TypeScript project is deprecated upstream) · checked %%versions-checked%%.

## What each guide covers

The two guides do not cover the same ground. The Python guide covers the whole framework; the TypeScript guide covers the workflow runtime and agents of the final LlamaIndex.TS release.

<CardGrid>
  <Card title="Python" icon="document">
    Readers, LlamaParse and ingestion pipelines; vector, summary, property-graph and multimodal indexes; query and chat engines (router, sub-question, hybrid retrieval); `FunctionAgent`, `ReActAgent`, `CodeActAgent` and `AgentWorkflow`; [Workflows](/llamaindex-guide/python/llamaindex_workflows/) as a framework in its own right (typed state, fan-out, streaming, human-in-the-loop, retries, checkpointing); memory; evaluation; serving with `WorkflowServer` and `llamactl`; observability and production deployment.
  </Card>
  <Card title="TypeScript" icon="random">
    The functional workflow API (`createWorkflow`, `workflowEvent`, `run`), the [`@llamaindex/workflow-core` engine](/llamaindex-guide/typescript/llamaindex_workflow_core/) (stateful middleware, snapshots, validation, retries), `agent(...)` / `multiAgent(...)` with tools, streaming, one vector-index RAG example from the `llamaindex` package, and a production guide for existing deployments.
  </Card>
</CardGrid>
