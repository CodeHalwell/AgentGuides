<Aside type="caution" title="Maintenance status">
  Microsoft moved AutoGen to maintenance mode in October 2025 alongside the launch of **Microsoft Agent Framework**, its successor, and in October 2026 marked the repository archived and no longer maintained (no bug or security fixes). The last release is 0.7.5 (September 2025). For new projects use the [Microsoft Agent Framework guide](/microsoft-agent-framework-guide/) or the [AG2 guide](/ag2-guide/).
</Aside>

## How the two diverged

- **2023–2024** — AutoGen 0.2 (`pyautogen`, `import autogen`) is developed at Microsoft Research.
- **November 2024** — AutoGen's original creators fork the 0.2 line as **AG2** under the `ag2ai` organisation, keeping the `import autogen` API. Microsoft continues `microsoft/autogen` independently.
- **January 2025** — Microsoft ships **AutoGen 0.4**, a ground-up rewrite split into `autogen-core`, `autogen-agentchat` and `autogen-ext` (imports `autogen_agentchat`, `autogen_core`, `autogen_ext`). It is not compatible with 0.2 or AG2.
- **October 2025** — Microsoft announces Agent Framework and puts AutoGen into maintenance mode; 0.7.5 is the final release.
- **July 2026** — AG2 1.0 replaces the Classic API in the `ag2` package; Classic continues separately as `autogen` in maintenance mode.
- **October 2026** — `microsoft/autogen` is marked archived.

The `pyautogen` name on PyPI now installs Microsoft's `autogen-agentchat`; the `autogen` name installs AG2 Classic. Pin explicitly.
