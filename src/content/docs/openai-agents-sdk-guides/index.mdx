## What's new

This guide targets **`openai-agents` %%version=openai-agents%%**. Releases since the guide was last revised (0.17.4, May 2026), from the upstream changelog:

- **0.24** — MCP tool annotations exposed on converted tools; run-wide tool exception formatting; many session, sandbox and approval fixes.
- **0.23** — Configurable MCP listing page limits; opt-in Docker removal protection for sandboxes; encrypted-history scan budget for sessions; Sandbox Agents no longer labelled beta.
- **0.22** — Stricter failure handling: failed or incomplete non-streaming Responses raise `ModelBehaviorError`; `OpenAIProvider(openai_client=...)` rejects `organization`/`project`; blocked terminal tool output is withheld from history.
- **0.21** — Requires `openai>=3.0.0,<4`; OpenAI HTTP integrations move to HTTPX2 (custom `http_client=` objects must migrate); provider-neutral testing utilities.
- **0.20** — Default model is now `gpt-5.6-luna`; MCP Python SDK v2 supported; `RunState.add_input()`; retry policies can approve unsafe replays explicitly.
- **0.19** — `ProgrammaticToolCallingTool`; `@tool` alias for `@function_tool`.
- **0.18** — Default Realtime model `gpt-realtime-2.1`.

See [What changed in 2026](./openai_agents_sdk_2025_features/#what-changed-in-2026) for the full table back to 0.7.

<Aside type="caution" title="Upgrading from older releases">
  - 0.21+ requires `openai` v3 (0.4–0.20 used v2). Code using the default client needs no change.
  - Python 3.10+ (3.9 dropped in 0.9).
  - Local MCP tool failures are returned to the model as error output by default (since 0.8); set `mcp_config={"failure_error_function": None}` for fail-fast behaviour.
  - Model refusals raise `ModelRefusalError` (since 0.15).
  - The default model changed in 0.16 and again in 0.20 — set `model=` explicitly if you depend on one.
</Aside>

## Install, minimal example

```python
from agents import Agent, Runner

agent = Agent(
    name="Assistant",
    instructions="You are a helpful assistant.",
)

result = Runner.run_sync(agent, "What is 2 + 2?")
print(result.final_output)
```
