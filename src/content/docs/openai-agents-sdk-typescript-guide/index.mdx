OpenAI's TypeScript library for agent applications, with the same primitives as the Python SDK: agents, tools (including other agents and MCP servers), handoffs, guardrails, human approvals, sessions and tracing, plus realtime voice agents for the browser and sandbox agents with a workspace. It runs on Node.js, Deno and Bun.

## What's new

This guide targets **`@openai/agents` %%version=@openai/agents%%**; all `@openai/agents*` packages share one version. The packages are versioned `0.Y.Z` and a minor release may break public interfaces, so pin an exact version and check this table before upgrading. Taken from the upstream changelogs; **Breaking** marks changes that can affect existing code.

| Release | Changes |
|---------|---------|
| 0.21 | **Breaking:** Runloop sandbox provider removed; usage-detail values need narrowing to numbers before arithmetic. |
| 0.20 | **Breaking:** automatic MCP tool discovery stops at 64 pages unless `maxListPages` is set; model calls after approval resumes count towards `maxTurns`. |
| 0.19 | Agent-tool streaming callbacks capped at 1024 pending events (`onStreamMaxPendingEvents`); resumed MCP calls bound to their original server; default tool-parse failures redacted. |
| 0.17–0.18 | Blocked tool outputs redacted from replay state; Unix-local and Docker sandbox file operations hardened. |
| 0.16 | Testing utilities in `@openai/agents/testing`: scripted models, sandbox sessions, Realtime. |
| 0.15 | **Breaking:** requires the `openai` Node SDK v7.2+ (Node.js 22+); default model `gpt-5.6-luna`; newer MCP protocol negotiation with legacy fallback. |
| 0.14 | Sensitive model and tool data no longer logged by default; default task and turn tracing with a per-run opt-out. |
| 0.13 | Default Realtime model `gpt-realtime-2.1`. |
| 0.11 | **Breaking:** local sandbox sources outside the base directory need explicit path grants; Realtime defaults upgraded. |
| 0.10 | **Breaking:** default model switched to `gpt-5.4-mini`. |
| 0.9 | Sandbox agents (`@openai/agents/sandbox`). |
| 0.7 | Opt-in model retry policies (`modelSettings.retry`, `retryPolicies`). |
| 0.5 | Responses WebSocket transport and `withResponsesWebSocketSession()`. |
| 0.4 | **Breaking:** Zod v3 support dropped; Zod v4 required for schema-based tools and outputs. |

Always set `model` explicitly if you depend on a particular model: the default has changed twice.

## Install, minimal example

```typescript
import { Agent, run } from '@openai/agents';

const agent = new Agent({
  name: 'Assistant',
  instructions: 'You are a helpful assistant.',
});

const result = await run(agent, 'What is 2 + 2?');
console.log(result.finalOutput);
```
