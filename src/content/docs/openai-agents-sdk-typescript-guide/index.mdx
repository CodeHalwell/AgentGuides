## What's new

This guide targets **`@openai/agents` %%version=@openai/agents%%** (all `@openai/agents*` packages share one version). Releases since the guide was last revised (0.11.6, May 2026), from the upstream changelogs:

- **0.21** — Runloop sandbox provider removed; usage-detail values need narrowing to numbers before arithmetic.
- **0.20** — Automatic MCP tool discovery stops at 64 pages unless `maxListPages` is set; model calls after approval resumes count towards `maxTurns`.
- **0.19** — Agent-tool streaming callbacks capped at 1024 pending events; resumed MCP calls bound to their original server; default tool-parse failures redacted.
- **0.17–0.18** — Blocked tool outputs redacted from replay state; sandbox file operations hardened.
- **0.16** — Testing utilities (`@openai/agents/testing`): scripted models, sandbox sessions, Realtime.
- **0.15** — Requires the `openai` Node SDK v7.2+; default model `gpt-5.6-luna`; newer MCP protocol negotiation.
- **0.14** — Sensitive model and tool data no longer logged by default; default task and turn tracing.
- **0.13** — Default Realtime model `gpt-realtime-2.1`.

<Aside type="caution" title="Upgrading from 0.11 or earlier">
  - Node.js 22+ is required (the `openai` v7 dependency sets `engines.node >=22`).
  - The default model changed in 0.15 — set `model` explicitly if you depend on one.
  - If you read usage details or rely on large MCP tool listings, check the 0.20 and 0.21 notes above.
</Aside>

## Install, minimal example

```typescript
import { Agent, run } from '@openai/agents';

const agent = new Agent({
  name: 'Assistant',
  instructions: 'You are a helpful assistant.',
});

const result = await run(agent, 'What is 2 + 2?');
console.log(result.finalOutput);
```
