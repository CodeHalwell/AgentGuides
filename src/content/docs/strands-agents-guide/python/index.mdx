## A first agent

```python
from strands import Agent, tool


@tool
def word_count(text: str) -> int:
    """Count the words in a piece of text.

    Args:
        text: The text to count.
    """
    return len(text.split())


agent = Agent(
    model="us.anthropic.%%model=anthropic%%",
    system_prompt="You are a concise assistant.",
    tools=[word_count],
)
print(agent("How many words are in 'the quick brown fox'?"))
```

This uses Amazon Bedrock with your AWS credentials. To use the Anthropic or OpenAI API directly, see [model providers](/strands-agents-guide/python/strands_comprehensive_guide/#anthropic-openai-and-others).

## Changes to know about

Facts from the installed packages, not a full changelog:

| Area | Change |
|------|--------|
| `strands-agents-tools` 0.8 | Most general-purpose tools (`shell`, `http_request`, `editor`, `calculator`, `current_time`, `memory`, `retrieve`, `think`, `batch`, ...) are deprecated in favour of `strands.vended_tools`, MCP servers or SDK features. They log a warning now and, per the package, an error log from 0.9.0. See the [replacement table](/strands-agents-guide/python/strands_tools_and_mcp/#deprecations-in-08). |
| MCP | Strands depends on the `mcp` 2.x SDK, where `FastMCP` is `MCPServer` (`mcp.server.mcpserver`). Servers written for `mcp` 1.x need that import changed. |
| Structured output | `Agent.structured_output()` is deprecated; pass `structured_output_model=` to the call and read `result.structured_output`. |
| Prompt caching | `cache_prompt` and `cache_tools` on `BedrockModel` are deprecated; use `cache_config=CacheConfig(...)`. |
| Default model | Without `model=`, the default Bedrock model is `global.anthropic.claude-sonnet-4-6` in this release, and it changes between releases. Always set the model. |
