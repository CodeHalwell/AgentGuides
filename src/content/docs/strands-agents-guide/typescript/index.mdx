## A first agent

```typescript
import { Agent, tool } from '@strands-agents/sdk'
import { z } from 'zod'

const wordCount = tool({
  name: 'word_count',
  description: 'Count the words in a piece of text.',
  inputSchema: z.object({ text: z.string() }),
  callback: ({ text }) => text.split(/\s+/).filter(Boolean).length,
})

const agent = new Agent({
  model: 'us.anthropic.%%model=anthropic%%',
  tools: [wordCount],
  printer: false,
})

console.log((await agent.invoke("How many words are in 'the quick brown fox'?")).toString())
```

<Aside type="caution" title="Where TypeScript lags Python">
  No `strands-agents-tools` equivalent (vended tools only), no `workflow` tool, no evals package, no real-time voice agent, fewer model providers (no LiteLLM, Ollama, Mistral or SageMaker classes), and graphs and swarms are unbounded unless you set limits. The full comparison is on the [production page](/strands-agents-guide/typescript/strands_typescript_production/#where-typescript-differs-from-python).
</Aside>

## Things that catch people out

- **`printer` defaults to `true`**: the agent writes its answer to stdout. Turn it off in servers.
- **`OpenAIModel` uses the Responses API by default**; pass `api: 'chat'` for Chat Completions (the Python class is the other way round).
- **Session IDs** may contain only lowercase letters, digits, hyphens and underscores.
- **Timeouts are milliseconds** and `Graph`/`Swarm` limits default to `Infinity`.
- **Optional peers**: install the OpenTelemetry and A2A packages within the ranges the SDK declares; `bedrock-agentcore` and the Strands A2A module want different major versions of `@a2a-js/sdk`.
