**Microsoft Agent Framework** brings together Semantic Kernel's enterprise foundations and AutoGen's multi-agent patterns in one SDK: agents over any chat model, tools and MCP, sessions and memory, graph workflows with checkpointing and human-in-the-loop, prebuilt orchestrations, A2A, and OpenTelemetry. The core is stable in Python and .NET; Go is in public preview. Several integration packages are still in beta or preview (in Python, for example, A2A, Anthropic, Bedrock, Ollama, Redis and Durable Task; in .NET, Foundry hosting, A2A and Azure Functions hosting).

## Release history

Dates are from PyPI, NuGet and the Go module proxy.

| Date | Release |
|---|---|
| 2025-10-01 | First public previews: `agent-framework` 1.0.0b251001 on PyPI, `Microsoft.Agents.AI` 1.0.0-preview.251001.1 on NuGet |
| 2026-02-20 | Python release candidates begin (1.0.0rc1) |
| 2026-04-02 | 1.0.0 GA on PyPI and NuGet |
| 2026-04-10 | Python 1.0.1; .NET 1.1.0 |
| 2026-09-01 | Go SDK v0.1.0 (public preview) |
| 2026-10-20 | Go SDK v0.2.0 |
| 2026-10-22 | Python 1.23.0: moves to MCP Python SDK 2.x (WebSocket transport and MCP tasks removed); AG-UI endpoints need an explicit authorization scope |
| 2026-10-23 | .NET 1.26.0: `AgentSessionStore.DeleteSessionAsync` is abstract again; request-time agent selection for AG-UI hosting |

Since GA, Python and .NET have shipped frequent minor releases, and some of them changed experimental APIs. Each language guide lists the breaking changes that affect its examples. Coming from Semantic Kernel or AutoGen? See Microsoft's [migration guide](https://learn.microsoft.com/agent-framework/migration-guide/from-semantic-kernel/).
