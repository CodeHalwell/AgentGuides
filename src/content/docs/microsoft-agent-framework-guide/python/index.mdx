Build single agents, graph workflows that checkpoint and wait for people, prebuilt multi-agent orchestrations, A2A endpoints and YAML-defined agents on the same primitives.

## Package status

- **Stable:** `agent-framework-core` (released in lockstep with the `agent-framework` meta package), `agent-framework-openai`, `agent-framework-foundry`, `agent-framework-orchestrations`, `agent-framework-declarative`, `agent-framework-ag-ui` and `agent-framework-github-copilot`.
- **Beta (`1.0.0bYYMMDD` versions, `--pre` when installed alone):** A2A, Anthropic, Claude Agent SDK, Bedrock, Ollama, Gemini, Mistral, Copilot Studio, Foundry hosting, Azure Functions, Durable Task, Redis, Cosmos DB, Mem0, DevUI and others.
- **Experimental APIs inside stable packages** emit an `ExperimentalWarning` on first use: FIDES security, evaluation, functional workflows, vector stores, `FileHistoryProvider`, and parts of the harness (`MemoryContextProvider`, `FileAccessProvider`, `BackgroundAgentsProvider`, `AgentLoopMiddleware`, `TodoFileStore`).
- **A2A:** `agent_framework.a2a` provides `A2AAgent` (client), `A2AExecutor` (server), `A2AAgentSession` and `A2AServiceSessionId`.

## Breaking changes worth knowing

Before GA (code written against the 2025 previews):

- `ChatAgent` → `Agent`, `ChatMessage` → `Message`, `AgentRunContext` → `AgentContext`, `AgentProtocol` → `SupportsAgentRun`; middleware's `next` parameter became `call_next` (1.0.0b260210).
- `@ai_function` → `@tool`, `AIFunction` → `FunctionTool` (1.0.0b260128); `create_agent` → `as_agent` (1.0.0b260116).
- `display_name` removed from agents; `middleware=` takes a list; `AggregateContextProvider` removed (pass several context providers instead) (1.0.0b260114).
- `AgentRunResponse` / `AgentRunResponseUpdate` renamed `AgentResponse` / `AgentResponseUpdate`.

Since GA:

- `WorkflowBuilder(output_executors=...)` is a deprecated alias for `output_from=`.
- Harness tool names changed in 1.7.0 (`add_todos` → `todos_add`, `set_mode` → `mode_set`, ...).
- Skills (1.11.0): `require_script_approval=` replaced by `disable_load_skill_approval` / `disable_read_skill_resource_approval` / `disable_run_skill_script_approval`; every skill tool needs approval unless you opt out.
- Functional workflows (1.14.0): `@workflow` returns a definition; call `.build()` before `.run()`.
- `AzureOpenAIChatClient` removed: use `OpenAIChatClient(azure_endpoint=..., credential=...)`.
- MCP (1.23.0, 2026-10-22): moved to MCP Python SDK 2.x (`mcp>=2.2,<3`). The WebSocket transport and MCP tasks are gone (`MCPWebsocketTool`, `MCPTaskOptions` and `task_options=` remain as deprecated stubs); `mcp` types use snake_case attributes; `http_client=` takes an `httpx2.AsyncClient`; `MCPTool.session` is deprecated (use `mcp_client=`); pruned installs also need `tenacity`. See the [MCP page](/microsoft-agent-framework-guide/python/microsoft_agent_framework_python_mcp/).
- AG-UI (since 1.23.0): `add_agent_framework_fastapi_endpoint()` needs `authorization_scope_resolver=` or `single_user=True` (see the [production guide](/microsoft-agent-framework-guide/python/microsoft_agent_framework_python_production_guide/#ag-ui-front-ends)).
- Docker shell tool (since 1.23.0, `agent-framework-tools`): `DockerShellTool(extra_run_args=...)` renamed `unsafe_extra_run_args=`.

Migrating from Semantic Kernel or AutoGen? See Microsoft's [migration guide](https://learn.microsoft.com/agent-framework/migration-guide/from-semantic-kernel/).

## Minimal example

```python
import asyncio
from agent_framework import Agent
from agent_framework.openai import OpenAIChatClient


async def main() -> None:
    agent = Agent(client=OpenAIChatClient(), instructions="You are a helpful assistant.")
    response = await agent.run("What is Microsoft Agent Framework?")
    print(response.text)


asyncio.run(main())
```
