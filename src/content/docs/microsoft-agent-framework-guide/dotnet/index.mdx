## What GA 1.0 brought (April 2026)

- **Stable APIs** with LTS commitment.
- **First-party service connectors** via `IChatClient`: Azure OpenAI, OpenAI, Anthropic Claude, Amazon Bedrock, Google Gemini, Ollama.
- **Unified orchestration** — sequential, concurrent, handoff, group chat, Magentic-One.
- **Azure App Service support**.

## Install, minimal example

```csharp
using Azure.AI.OpenAI;
using Azure.Identity;
using Microsoft.Agents.AI;
using OpenAI.Chat;

var client = new AzureOpenAIClient(
    new Uri(Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT")!),
    new DefaultAzureCredential()
);

// AsAIAgent (Microsoft.Agents.AI.OpenAI) wraps the OpenAI SDK ChatClient in a ChatClientAgent.
AIAgent agent = client
    .GetChatClient("gpt-4o")
    .AsAIAgent(instructions: "You are a helpful assistant.");

AgentSession session = await agent.CreateSessionAsync();   // multi-turn state
var response = await agent.RunAsync("What is 15 + 27?", session);
Console.WriteLine(response.Text);
```

If you already have an `IChatClient` (from `Microsoft.Extensions.AI`), construct the agent directly: `new ChatClientAgent(chatClient, instructions: "...")`. Earlier previews used `AgentThread` / `GetNewThread()` and `CreateAIAgent(...)`; the GA names are `AgentSession` / `CreateSessionAsync()` and `AsAIAgent(...)`.

<Aside type="note" title="Compiled against the current packages">
  The comprehensive guide, recipes and feature tour were rewritten on %%versions-checked%% so that every C# example compiles against `Microsoft.Agents.AI` %%version=Microsoft.Agents.AI%% and its companion packages. Earlier drafts used helpers that never shipped (`AddAgentFactory`, `UseAzureOpenAI`, `AddCosmosDBState`, `MapAgents`, `AddConditionalEdge`, `AgentGraph`); the real building blocks are `ChatClientAgent` / `AsAIAgent`, `AgentSession`, `AIAgentBuilder`, `AddAIAgent` (hosting), `WorkflowBuilder` / `AgentWorkflowBuilder` / `InProcessExecution` (workflows) and `MapA2AJsonRpc` (A2A hosting).
</Aside>
