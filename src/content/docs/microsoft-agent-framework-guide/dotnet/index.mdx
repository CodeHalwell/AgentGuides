**Unified .NET SDK that merges Semantic Kernel and AutoGen** (generally available since 2 April 2026). Build C# agents with `ChatClientAgent`, orchestrate multi-agent workflows, integrate with Azure AI services via managed identity, and stream via SignalR or SSE.


<Aside type="caution" title="Migrating from the previews">
  `ChatClientAgentOptions` has no `Instructions` property: pass instructions to the `ChatClientAgent` constructor or `AsAIAgent(...)`, or set `ChatOptions.Instructions`. The core packages (`Microsoft.Agents.AI`, `.OpenAI`, `.Workflows`, `.Harness`, `.Anthropic`, `.GitHub.Copilot`) are stable; hosting, Foundry, A2A, DevUI and Azure Functions packages still need `--prerelease`.

## Packages

- **Stable:** `Microsoft.Agents.AI` (agents, sessions, context providers, harness providers, evaluation), `Microsoft.Agents.AI.OpenAI`, `Microsoft.Agents.AI.Workflows`, `Microsoft.Agents.AI.Workflows.Declarative`, `Microsoft.Agents.AI.Harness`, `Microsoft.Agents.AI.Anthropic`, `Microsoft.Agents.AI.GitHub.Copilot`.
- **Preview:** `Microsoft.Agents.AI.Foundry`, `.Foundry.Hosting`, `.Hosting` (and its OpenAI, A2A and AG-UI endpoints), `.A2A`, `.DevUI`, `.Hosting.AzureFunctions`, `.DurableTask`, `.CosmosNoSql`, `.CopilotStudio`, `.AzureAI.Persistent`.
- **Other models** (Ollama, Bedrock, Gemini and so on) plug in through any `Microsoft.Extensions.AI` `IChatClient` implementation; there are no separate `Microsoft.Agents.AI.*` packages for them.

## Install, minimal example

```csharp
using Azure.AI.OpenAI;
using Azure.Identity;
using Microsoft.Agents.AI;
using OpenAI.Chat;

var client = new AzureOpenAIClient(
    new Uri(Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT")!),
    new DefaultAzureCredential()
);

// AsAIAgent (Microsoft.Agents.AI.OpenAI) wraps the OpenAI SDK ChatClient in a ChatClientAgent.
AIAgent agent = client
    .GetChatClient("%%model=openai%%")
    .AsAIAgent(instructions: "You are a helpful assistant.");

AgentSession session = await agent.CreateSessionAsync();   // multi-turn state
var response = await agent.RunAsync("What is 15 + 27?", session);
Console.WriteLine(response.Text);
```

If you already have an `IChatClient` (from `Microsoft.Extensions.AI`), construct the agent directly: `new ChatClientAgent(chatClient, instructions: "...")`. Earlier previews used `AgentThread` / `GetNewThread()` and `CreateAIAgent(...)`; the GA names are `AgentSession` / `CreateSessionAsync()` and `AsAIAgent(...)`.

<Aside type="note" title="Compiled against the current packages">
  The comprehensive guide, recipes and feature tour were rewritten on %%versions-checked%% so that every C# example compiles against `Microsoft.Agents.AI` %%version=Microsoft.Agents.AI%% and its companion packages. The building blocks are `ChatClientAgent` / `AsAIAgent`, `AgentSession`, `AIAgentBuilder`, `AddAIAgent` (hosting), `WorkflowBuilder` / `AgentWorkflowBuilder` / `InProcessExecution` (workflows) and `MapA2AJsonRpc` (A2A hosting).
</Aside>
