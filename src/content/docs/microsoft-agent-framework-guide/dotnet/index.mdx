**The .NET SDK that succeeds Semantic Kernel's agent features and AutoGen** (generally available since 2 April 2026). Build C# agents with `ChatClientAgent` on any `IChatClient`, compose them in graph workflows and prebuilt orchestrations, serve them over OpenAI-compatible, A2A and AG-UI endpoints, and use Azure services through managed identity.

<CardGrid>
  <Card title="Install" icon="rocket">
    ```bash
    dotnet add package Microsoft.Agents.AI --version %%version=Microsoft.Agents.AI%%
    dotnet add package Microsoft.Agents.AI.OpenAI   # AsAIAgent() for OpenAI / Azure OpenAI
    ```
  </Card>
  <Card title="Version" icon="information">
    `Microsoft.Agents.AI` **%%version=Microsoft.Agents.AI%%** (checked %%versions-checked%%) · .NET 8.0+, also .NET Standard 2.0 / .NET Framework 4.7.2
  </Card>
  <Card title="Best for" icon="puzzle">
    Enterprise .NET agents, Azure-native deployments, ASP.NET Core hosting, multi-agent workflows.
  </Card>
</CardGrid>

<Aside type="caution" title="Migrating from the previews">
  `ChatClientAgentOptions` has no `Instructions` property: pass instructions to the `ChatClientAgent` constructor or `AsAIAgent(...)`, or set `ChatOptions.Instructions`. The core packages (`Microsoft.Agents.AI`, `.OpenAI`, `.Workflows`, `.Harness`, `.Anthropic`, `.GitHub.Copilot`) are stable; hosting, Foundry, A2A, DevUI, MCP-extension and Azure Functions packages still need `--prerelease`.
</Aside>

Other models (Ollama, Bedrock, Gemini and so on) plug in through any `Microsoft.Extensions.AI` `IChatClient` implementation; there are no separate `Microsoft.Agents.AI.*` packages for them. MCP clients and servers come from the official C# SDK, `ModelContextProtocol`.

## Install, minimal example

```csharp
using Azure.AI.OpenAI;
using Azure.Identity;
using Microsoft.Agents.AI;
using OpenAI.Chat;

var client = new AzureOpenAIClient(
    new Uri(Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT")!),
    new DefaultAzureCredential()
);

// AsAIAgent (Microsoft.Agents.AI.OpenAI) wraps the OpenAI SDK ChatClient in a ChatClientAgent.
AIAgent agent = client
    .GetChatClient("%%model=openai%%")
    .AsAIAgent(instructions: "You are a helpful assistant.");

AgentSession session = await agent.CreateSessionAsync();   // multi-turn state
var response = await agent.RunAsync("What is 15 + 27?", session);
Console.WriteLine(response.Text);
```

If you already have an `IChatClient` (from `Microsoft.Extensions.AI`), construct the agent directly: `new ChatClientAgent(chatClient, instructions: "...")`. Earlier previews used `AgentThread` / `GetNewThread()` and `CreateAIAgent(...)`; the GA names are `AgentSession` / `CreateSessionAsync()` and `AsAIAgent(...)`.
