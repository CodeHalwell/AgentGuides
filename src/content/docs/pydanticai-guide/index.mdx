## What's new

Condensed version history. The upstream [changelog](https://pydantic.dev/docs/ai/changelog/) has the full detail.

| Version | Date | Highlights |
|---------|------|-----------|
| 1.0.0 | Sep 2025 | API stability commitment for the 1.x line. `FallbackModel`, `ApprovalRequiredToolset` and `DeferredToolRequests` already present. |
| 1.1–1.40 | Sep 2025 – Jan 2026 | AG-UI adapter (`AGUIAdapter`), `WebFetchTool`, embeddings API (`Embedder`). |
| 1.41–1.75 | Jan–Apr 2026 | `ConcurrencyLimiter`; capabilities system (`AbstractCapability`, `Hooks`) and `AgentSpec`. |
| 1.76–1.94 | Apr–May 2026 | `DeferredLoadingToolset` and `ToolSearch`; `ToolOrOutput`. |
| 1.95–1.107 | May–Jun 2026 | V2 removals announced as `PydanticAIDeprecationWarning`s; `NativeOrLocalTool` capabilities; `MCPToolset` (1.97). |
| **2.0.0** | **Jun 2026** | **Major version.** `openai:` means the Responses API; `builtin_tools=` → `capabilities=[NativeTool(...)]`; `MCPServer*` → `MCPToolset`; `result.usage` is a property; `run_stream_events()` is a context manager; default `end_strategy='graceful'`; `ModelProfile` is a `TypedDict`; slimmer default extras; graph persistence removed. See [Upgrading from V1](./pydantic_ai_comprehensive_guide/#upgrading-from-v1). |
| 2.10–2.13 | Jul 2026 | `SelectModel` and `ResolveModelId` capabilities. |
| 2.14 | Jul 2026 | Durability capabilities (`TemporalDurability`, `DBOSDurability`, `PrefectDurability`); the wrapper agents are deprecated. |
| 2.15–2.40 | Jul–Sep 2026 | `ToolFailed`, `AdvisorTool`, `CancellationToken` / `RunCancelled`, realtime voice sessions (`agent.realtime()`). |
| 2.51–2.59 | Sep–Oct 2026 | `Caching` and `LocalWorkspace` capabilities. |
| 2.60 | Oct 2026 | `RetryPromptPart` deprecated for `ToolReturnPart(outcome='retried')` and `RetryFeedbackPart`; `'max'` thinking level; `FileUnderstanding` capability; `ModelSelectionContext` gains `usage_limits`, `deadline`, `run_id`, `conversation_id`. |
| 2.61 | Oct 2026 | `Citations` capability and `TextPart.citations`; `thinking=False` sends the lowest accepted level on models that cannot disable thinking; async `auth` functions for hosted MCP capabilities. |
| 2.62–2.63 | Oct 2026 | `BatchModelRequests` capability and `model_request_batch` for provider batch APIs; `PendingModelResponse`; `OpenAICompatibleProvider`; `ModelAuthenticationError`, `ModelNotFoundError` and `ModelRequestRejectedError`. |

Version ranges are where a feature first appears in the published wheels; the changelog has exact versions.

## Install, minimal example

```python
from pydantic import BaseModel
from pydantic_ai import Agent

class Answer(BaseModel):
    value: int
    reasoning: str

agent = Agent('openai:%%model=openai%%', output_type=Answer)

result = agent.run_sync("What is 15 + 27?")
print(result.output)  # Answer(value=42, reasoning='...')
```
