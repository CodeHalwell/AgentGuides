## What's new

Condensed version history. The upstream [changelog](https://pydantic.dev/docs/ai/changelog/) has the full detail.

| Version | Date | Highlights |
|---------|------|-----------|
| 1.0.0 | Sep 2025 | API stability commitment for the 1.x line. |
| 1.84–1.88 | Apr 2026 | Embeddings API, AG-UI adapter, `ApprovalRequiredToolset`, `DeferredLoadingToolset`; capabilities system introduced (`Hooks`, `AbstractCapability`, `ModelProfile`). |
| 1.89–1.99 | May 2026 | `DeferredToolCalls` → `DeferredToolRequests`; `AgentRun` exported; `ConcurrencyLimiter`; `pydantic_ai.ui.ag_ui`; `common_tools`. |
| 1.100–1.107 | May–Jun 2026 | Most V2 removals announced via deprecation warnings; `MCPToolset`; native tool suite; `GraphBuilder`; agent graph nodes public. |
| **2.0.0** | **Jun 2026** | **Major version.** `openai:` means the Responses API; `builtin_tools=` → `capabilities=[NativeTool(...)]`; `MCPServer*` → `MCPToolset`; `result.usage` is a property; `run_stream_events()` is a context manager; default `end_strategy='graceful'`; `ModelProfile` is a `TypedDict`; slimmer default extras; graph persistence removed. See [Upgrading from V1](./pydantic_ai_comprehensive_guide/#upgrading-from-v1). |
| 2.1–2.13 | Jun–Jul 2026 | `FallbackModel` response handlers, `Embedder`, server-side compaction, `OnlineEvaluation`, `NativeOrLocalTool` with the `MCP` / `WebSearch` / `WebFetch` / `ImageGeneration` / `Thinking` capabilities, `ToolOrOutput`, `AgentSpec` YAML/JSON. |
| 2.14 | Jul 2026 | Durability capabilities (`TemporalDurability`, `DBOSDurability`, `PrefectDurability`) — the wrapper agents are deprecated; `SelectModel` / `ResolveModelId`. |
| 2.15–2.40 | Jul–Sep 2026 | `ToolFailed`, `AdvisorTool`, `CancellationToken` / `RunCancelled`, `RunUsage.cost`, realtime voice sessions (`agent.realtime()`). |
| 2.41–2.59 | Sep–Oct 2026 | `Caching` and `LocalWorkspace` capabilities, plus steady provider and model additions. |

## Install, minimal example

```python
from pydantic import BaseModel
from pydantic_ai import Agent

class Answer(BaseModel):
    value: int
    reasoning: str

agent = Agent('openai:gpt-4o', output_type=Answer)

result = agent.run_sync("What is 15 + 27?")
print(result.output)  # Answer(value=42, reasoning='...')
```
