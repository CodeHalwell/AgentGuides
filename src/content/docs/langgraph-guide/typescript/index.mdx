**TypeScript port of LangGraph.** Same graph-based mental model as the Python version — explicit state, durable checkpoints, conditional routing — with type-safe streaming, Zod/Standard Schema state, and `ReducedValue`/`UntrackedValue` field types. Ready-made agents come from `createAgent` in the `langchain` package.

**Current version: `@langchain/langgraph` %%version=@langchain/langgraph%%** (checked %%versions-checked%%). Node 18+.

## What's new since 1.3

- **1.5.x** — parallel writes are ordered by task path (as in Python), plus fixes to `DeltaChannel`, exit durability, interrupt resumption and node-cache persistence. No API removals.
- **1.4.x** — node-level `timeout` (`NodeTimeoutError`) and `errorHandler`; `StateGraph.setNodeDefaults()` for graph-wide `retryPolicy`/`cachePolicy`; cooperative draining with `RunControl`/`GraphDrained`; `DeltaChannel` (beta); per-node `tracePolicy`; `GraphCallbackHandler`; `RemoteGraph` v3 streaming.
- **1.3.0** — `MessagesZodState`/`MessagesZodMeta`; `STREAM_EVENTS_V3_MODES`; `createGraphRunStream`/`GraphRunStream`/`SubgraphRunStream`; stream transformers (`createLifecycleTransformer`, `createMessagesTransformer`, `createSubgraphDiscoveryTransformer`, `createValuesTransformer`); schema utilities (`isSerializableSchema`, `isStandardSchema`, `getJsonSchemaFromSchema`, `getSchemaDefaultGetter`); `pushMessage`.
- **1.2.x** — Standard JSON Schema state (Zod 4, Valibot, ArkType), `StateSchema`, `ReducedValue`, `UntrackedValue`.

See the [comprehensive guide](/langgraph-guide/typescript/langchain_langgraph_comprehensive_guide/#later-additions-14--15) for details.

<Aside type="caution" title="Where did createReactAgent go?">
  `createReactAgent` in `@langchain/langgraph/prebuilt` still works but is deprecated in favour of `createAgent` from the `langchain` package (`npm install langchain`). Do not install `@langgraphjs/toolkit`: earlier revisions of this guide recommended it, but that npm name is a security placeholder, not a LangGraph package.
</Aside>

## Install, minimal example

```bash
npm install @langchain/langgraph@%%version=@langchain/langgraph%% @langchain/core
```

```typescript
import { StateGraph, MessagesAnnotation, START, END, MemorySaver } from '@langchain/langgraph';
import { AIMessage, HumanMessage } from '@langchain/core/messages';

const graph = new StateGraph(MessagesAnnotation)
  .addNode('respond', async (state) => ({
    messages: [new AIMessage(`You said: ${state.messages.at(-1)?.content}`)],
  }))
  .addEdge(START, 'respond')
  .addEdge('respond', END)
  .compile({ checkpointer: new MemorySaver() });

const result = await graph.invoke(
  { messages: [new HumanMessage('Hello')] },
  { configurable: { thread_id: 'session-1' } }
);
console.log(result);
```
