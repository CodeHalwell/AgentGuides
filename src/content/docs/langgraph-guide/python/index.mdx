**Low-level orchestration for stateful, long-running LLM agents.** LangGraph models your agent as a graph of nodes and edges with explicit state, durable checkpoints, and first-class human-in-the-loop.

**Current version: `langgraph` %%version=langgraph%%** (checked %%versions-checked%%) · Python 3.10+.

<Aside type="caution" title="Corrections to older material">
  - Build tool-calling agents with `langchain.agents.create_agent` (in the `langchain` package). `langgraph.prebuilt.create_react_agent` is deprecated and its `pre_model_hook`/`post_model_hook` map to middleware ([Chapter 8](/langgraph-guide/python/chapter-08-middleware-hooks/#migrating-from-create_react_agent-hooks)).
  - The default `recursion_limit` is 10007, not 25. Set it explicitly for agent loops.
  - `ToolNode`'s default error handling catches only invalid-argument errors; other tool exceptions propagate unless you pass `handle_tool_errors=True`.
  - `durability=` is an argument to `invoke`/`stream`, not `compile()`, and interrupts work under every mode.
  - Node timeouts work only on `async` nodes; `compile()` rejects a sync node with a timeout.
  - `SqliteSaver.from_conn_string(...)` and `PostgresSaver.from_conn_string(...)` are context managers.
  - `InMemoryStore` has no TTL support; use `SqliteStore` or `PostgresStore` with a `ttl` config.
  - "LangGraph Cloud" / "LangGraph Platform" is now LangSmith Deployment; the server is the Agent Server.
</Aside>

## Minimal example

```python
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import InMemorySaver
from typing_extensions import TypedDict

class State(TypedDict):
    message: str
    response: str

def process(state: State) -> dict:
    return {"response": f"Processed: {state['message']}"}

builder = StateGraph(State)
builder.add_node("process", process)
builder.add_edge(START, "process")
builder.add_edge("process", END)

graph = builder.compile(checkpointer=InMemorySaver())

result = graph.invoke(
    {"message": "Hello"},
    config={"configurable": {"thread_id": "user-1"}},
)
print(result)
```
