**Low-level orchestration for stateful, long-running LLM agents.** Explicit state, durable checkpoints, conditional routing, human-in-the-loop. Available in Python and TypeScript with the same concepts.

**Current versions:** Python `langgraph` %%version=langgraph%% · TypeScript `@langchain/langgraph` %%version=@langchain/langgraph%% (checked %%versions-checked%%).

## Not sure which language?

- **Python** has the larger ecosystem, more recipes, and a ten-chapter tutorial.
- **TypeScript** suits apps that are already Node or browser based; the primitives are the same and the builder is fully typed.
