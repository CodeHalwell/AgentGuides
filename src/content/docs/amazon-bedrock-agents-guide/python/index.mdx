Write the agent with **Strands Agents** (or LangGraph, CrewAI, the OpenAI Agents SDK and others). Run it on **AgentCore Runtime** by wrapping it in `BedrockAgentCoreApp` and deploying it with the AgentCore CLI. If you don't need your own code, declare a **managed harness** instead: model, system prompt and tools as configuration, run by AgentCore.

## Minimal example

A Strands agent served with the AgentCore Runtime contract (`POST /invocations` and `GET /ping` on port 8080):

```python
from bedrock_agentcore import BedrockAgentCoreApp
from strands import Agent

app = BedrockAgentCoreApp()
agent = Agent(model="us.anthropic.%%model=anthropic%%")


@app.entrypoint
def invoke(payload, context):
    prompt = payload.get("prompt")
    if not isinstance(prompt, str):
        raise ValueError("prompt must be a string")
    return {"result": str(agent(prompt))}


if __name__ == "__main__":
    app.run()
```

Run it with `python main.py` and `curl -X POST localhost:8080/invocations -d '{"prompt": "Hello"}'`. [Getting started](/amazon-bedrock-agents-guide/python/bedrock_agentcore_comprehensive_guide/#getting-started) shows how to deploy it.
