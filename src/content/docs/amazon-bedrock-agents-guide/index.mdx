AWS's current agent stack has two layers. **Amazon Bedrock AgentCore** is where agents run: session-isolated hosting (Runtime), a config-declared agent loop (the managed **Harness**), and Memory, Gateway, Identity, Code Interpreter, Browser and Observability services. **Strands Agents** is AWS's open-source SDK for writing the agent itself, although AgentCore Runtime hosts agents written with any framework. The original **Bedrock Agents** service, now called *Agents Classic*, is covered for existing users.

## Which AWS option?

| You want | Use | Start here |
|----------|-----|------------|
| A managed agent declared as configuration (model, prompt, tools, memory) | **AgentCore Harness** | [Managed harness](/amazon-bedrock-agents-guide/python/bedrock_agentcore_comprehensive_guide/#managed-harness) |
| Your own agent code (Strands, LangGraph, CrewAI, OpenAI Agents SDK…) hosted by AWS | **AgentCore Runtime** | [Getting started](/amazon-bedrock-agents-guide/python/bedrock_agentcore_comprehensive_guide/#getting-started) |
| An agent loop in your own process, on Bedrock or another provider | **Strands Agents** | [Strands Agents guide](/strands-agents-guide/) |
| To keep running an existing Bedrock Agents agent | **Agents Classic** | [Classic reference](/amazon-bedrock-agents-guide/python/bedrock_agents_comprehensive_guide/) |

The harness and code-defined agents both run on AgentCore Runtime, and the CLI can export a harness to Strands code when you outgrow configuration.

## What's new

- **Bedrock Agents Classic in maintenance mode (30 July 2026)**: closed to accounts without prior usage. AWS names the managed harness as the first migration target and code-defined agents on Runtime for custom orchestration, prompt overrides or multi-agent collaboration.
- **AgentCore**: generally available since October 2025. Recent additions include the managed harness, A2A and AG-UI server protocols on Runtime, direct code deployment (Python and Node.js), Evaluations, Policy and Payments. The npm **AgentCore CLI** (`@aws/agentcore`) is the recommended deployment tool. It scaffolds harness or code projects, deploys them with CDK, imports Classic agents (`agentcore add runtime --agent-id`) and exports a harness to Strands code. CLI 1.0 changed the command set from 0.x; `agentcore migrate` converts a 0.x project.
- **Strands Agents**: 1.0 shipped in July 2025, with minor releases since. Recent releases added `Agent.as_tool`, A2A client and server support, `CacheConfig` for prompt caching (replacing the deprecated `cache_prompt` and `cache_tools`), sandboxes, plugins and Agent Skills.
- **Claude 5.5 models on Bedrock**: `anthropic.claude-opus-5-5`, `anthropic.claude-sonnet-5-5` and `anthropic.claude-haiku-5-5`, usually called through inference profiles such as `us.anthropic.claude-sonnet-5-5`.
