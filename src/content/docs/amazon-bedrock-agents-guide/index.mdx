**AWS-native agents on Bedrock.** The current stack is **AgentCore** (managed, session-isolated hosting plus memory, gateway, identity, sandboxed tools and observability) with agents written in the open-source **Strands Agents SDK** or any other framework. The original **Bedrock Agents** service (now "Agents Classic") is still covered for existing users.

<Aside type="tip" title="Two layers, one platform">
  **Strands** (or LangGraph, CrewAI, ADK…) is how you write the agent. **AgentCore** is where it runs in production. They are complementary: wrap a Strands agent in `BedrockAgentCoreApp` and deploy it with the AgentCore CLI.
</Aside>

<Aside type="caution" title="Bedrock Agents Classic is in maintenance mode">
  Amazon Bedrock Agents (now "Agents Classic") stopped accepting new customers on 30 July 2026. Existing customers can keep using it, and the Classic pages here remain accurate for them; AWS recommends AgentCore for new work. See [AWS's migration guidance](https://docs.aws.amazon.com/bedrock/latest/userguide/agents-classic-maintenance-mode.html).
</Aside>

## What's new

- **Bedrock Agents Classic in maintenance mode (30 July 2026)** — closed to new customers; AgentCore (managed harness or code-defined agents on Runtime) is the migration target.
- **AgentCore** — generally available since October 2025. Recent additions include the managed **Harness** (config-declared agent loop), A2A and AG-UI server protocols on Runtime, direct code deployment (Python and Node.js), and Policy, Evaluations and Payments services. The recommended deployment tool is now the npm **AgentCore CLI** (`@aws/agentcore`).
- **Strands Agents** — continuous minor releases since 1.0 (July 2025). Current releases add `Agent.as_tool`, A2A client/server support (`A2AAgent`, `A2AServer`), `CacheConfig` for prompt caching (replacing the deprecated `cache_prompt` / `cache_tools`), sandboxes, plugins and skills.
- **Claude 5.5 models on Bedrock** — `anthropic.claude-opus-5-5`, `anthropic.claude-sonnet-5-5` and `anthropic.claude-haiku-5-5`, usually called through inference profiles such as `us.anthropic.claude-sonnet-5-5`.
- **Guide rewrite (October 2026)** — the AgentCore, Strands, A2A, recipes and multi-agent pages were rewritten against the real SDKs; earlier versions contained APIs that never existed.

## Install, minimal example

A Strands agent, ready to deploy to AgentCore Runtime:

```python
from bedrock_agentcore import BedrockAgentCoreApp
from strands import Agent

app = BedrockAgentCoreApp()
agent = Agent(model="us.anthropic.claude-sonnet-5-5")


@app.entrypoint
def invoke(payload, context):
    return {"result": str(agent(payload["prompt"]))}


if __name__ == "__main__":
    app.run()  # serves POST /invocations on port 8080
```

Invoking an existing Bedrock Agents (Classic) agent:

```python
import boto3

client = boto3.client("bedrock-agent-runtime")

response = client.invoke_agent(
    agentId="AGENT_ID",
    agentAliasId="ALIAS_ID",
    sessionId="session-1",
    inputText="Help me analyse Q3 sales data.",
)

print("".join(e["chunk"]["bytes"].decode() for e in response["completion"] if "chunk" in e))
```
