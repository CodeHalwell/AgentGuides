**Microsoft's SDK for building AI apps and agents in .NET.** Semantic Kernel for C# brings a kernel of AI services and plugins, function calling, agents and orchestrations, `Microsoft.Extensions.VectorData` vector stores and MCP tools into ASP.NET Core, Azure Functions and worker services, with OpenTelemetry built in.

<Aside type="caution" title="Semantic Kernel or Agent Framework?">
  [Microsoft Agent Framework](/microsoft-agent-framework-guide/dotnet/) (`Microsoft.Agents.AI`) is the successor to Semantic Kernel (same team) and has been generally available since April 2026. Semantic Kernel 1.x is still supported — critical bug and security fixes for at least a year after Agent Framework's GA — but most new features go to Agent Framework. Start new agent projects there; existing SK agents can be wrapped with `.AsAIAgent()` and migrated gradually.
</Aside>

## Recent changes worth knowing

- **Vector store connectors renamed** (July 2026): the `Microsoft.SemanticKernel.Connectors.*` vector store packages (InMemory, AzureAISearch, Qdrant, Redis, SqlServer, PgVector, SqliteVec, CosmosNoSql, Weaviate ...) are deprecated in favour of `CommunityToolkit.VectorData.*` (for example `.PgVector`, `.AzureCosmosDB`; `.SqliteVec` is still `-preview`).
- **Agent Framework interop**: every SK agent type has `.AsAIAgent()`, returning a `Microsoft.Agents.AI.AIAgent`.
- **Planners** are deprecated on NuGet (last `1.47.0-preview`); use function calling.
- Orchestration, runtime, OpenAI/Azure AI agent packages are `-preview`; A2A, Copilot Studio, Bedrock, Process and most non-OpenAI connector packages are `-alpha`.

## Install, minimal example

```csharp
using Microsoft.SemanticKernel;
using Microsoft.SemanticKernel.Agents;

var builder = Kernel.CreateBuilder();
builder.AddOpenAIChatCompletion("%%model=openai-small%%", Environment.GetEnvironmentVariable("OPENAI_API_KEY")!);
var kernel = builder.Build();

ChatCompletionAgent agent = new()
{
    Name = "Assistant",
    Instructions = "You are a helpful assistant.",
    Kernel = kernel,
};

await foreach (var item in agent.InvokeAsync("What is 15 + 27?"))
{
    Console.WriteLine(item.Message.Content);
}
```

`ChatCompletionAgent` is in `Microsoft.SemanticKernel.Agents.Core` (`dotnet add package Microsoft.SemanticKernel.Agents.Core --version %%version=Microsoft.SemanticKernel%%`).
