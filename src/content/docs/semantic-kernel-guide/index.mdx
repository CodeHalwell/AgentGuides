<Aside type="caution" title="Semantic Kernel and Microsoft Agent Framework">
  [Microsoft Agent Framework](/microsoft-agent-framework-guide/) is the successor to Semantic Kernel (and AutoGen), built by the same team, and has been generally available since April 2026. Microsoft continues to support Semantic Kernel 1.x — critical bug and security fixes, for at least a year after Agent Framework's GA — but most new features go to Agent Framework. **New agent projects: start on Agent Framework. Existing SK code: keep it updated and migrate gradually** — SK functions convert to Agent Framework tools (Python) and SK agents wrap as Agent Framework agents (.NET).
</Aside>

## Things that changed since older tutorials

- **Planners are gone** — removed from Python in 1.33.0 and deprecated in .NET. Use function calling.
- **Memory stores became vector stores** — Python redesigned the API in 1.34.0; .NET uses `Microsoft.Extensions.VectorData` with `CommunityToolkit.VectorData.*` connectors.
- **Agents use threads** — `get_response(messages=..., thread=...)` / `InvokeAsync(message, thread)`; `AgentGroupChat` is superseded by orchestrations (sequential, concurrent, group chat, hand-off, Magentic).
- **MCP** — Python has MCP plugins and `kernel.as_mcp_server()`; .NET uses the official MCP C# SDK with `AsKernelFunction()`.
