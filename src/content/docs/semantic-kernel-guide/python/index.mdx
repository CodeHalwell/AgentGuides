<Aside type="caution" title="Semantic Kernel or Agent Framework?">
  [Microsoft Agent Framework](/microsoft-agent-framework-guide/python/) is the successor to Semantic Kernel (same team) and has been generally available since April 2026. Semantic Kernel 1.x is still supported — critical bug and security fixes for at least a year after Agent Framework's GA — but most new features go to Agent Framework. Start new agent projects there; keep existing SK code and migrate gradually. SK's built-in bridge, `KernelFunction.as_agent_framework_tool()`, is broken against every released Agent Framework version (it imports a class that was renamed), so use the [small wrapper in the migration section](/semantic-kernel-guide/python/semantic_kernel_comprehensive_python/#16-migrating-to-microsoft-agent-framework) instead.
</Aside>

## Recent releases

- **1.45.0 (October 2026)**, **1.44.x (July–August 2026)**, **1.43.0 (June 2026)**, **1.42.0 (May 2026)** — maintenance releases: connector and dependency updates and bug fixes. 1.42.0 raised the `mcp` requirement to 1.26 or later.
- Earlier milestones still relevant today: planners removed (1.33.0); vector store API redesigned (1.34.0); `KernelFunction.as_agent_framework_tool()` added for Agent Framework interop (1.38.0), but it still targets a pre-1.0 Agent Framework API and fails with current releases.
- `AzureAIAgent` needs `azure-ai-projects` 1.x (`pip install "azure-ai-projects<2"`); pip otherwise picks 2.x, which it does not support.

A plain `pip install semantic-kernel` works; `--pre` is not needed, even though one Azure dependency is a pre-release.

## Install, minimal example

```python
import asyncio
from semantic_kernel.agents import ChatCompletionAgent
from semantic_kernel.connectors.ai.open_ai import OpenAIChatCompletion

agent = ChatCompletionAgent(
    service=OpenAIChatCompletion(ai_model_id="%%model=openai-small%%"),   # reads OPENAI_API_KEY
    name="Assistant",
    instructions="You are a helpful assistant.",
)

async def main():
    response = await agent.get_response(messages="What is 15 + 27?")
    print(response.message.content)

asyncio.run(main())
```
