**AG2 is a community fork of AutoGen 0.2**, started in November 2024 by AutoGen's original authors and developed independently of Microsoft's AutoGen. With **AG2 1.0 (July 2026)** the project replaced its AutoGen-era API: `pip install ag2` now gives you an async, protocol-driven framework imported as `ag2`, built around `Agent`, `@tool`, typed events and a multi-agent **Network**. The old `autogen.*` API lives on as **AG2 Classic**.

<Aside type="caution" title="ag2 1.x is not a drop-in upgrade from 0.x">
  If your code says `import autogen` or `from autogen import ConversableAgent, GroupChat`, you are on **AG2 Classic**. Upgrading to `ag2>=1.0` removes that namespace entirely. Either stay on Classic — published on PyPI as `autogen` (or pin `ag2<1.0`), in maintenance mode with security and critical fixes only, covered in the [AG2 Classic section](/ag2-guide/classic/) — or port to the new API with the [migration guide](/ag2-guide/classic/ag2_classic_migration_guide/). (`pip install ag2-classic`, mentioned upstream, is not a PyPI package; install `autogen`.)
</Aside>

<Aside type="note" title="AG2 is not Microsoft AutoGen">
  Microsoft's own AutoGen (`autogen-agentchat` / `autogen-core`, the 0.4+ actor-model rewrite) is a separate project covered in the [AutoGen guide](/autogen-guide/). Note that the `pyautogen` name on PyPI now installs Microsoft's `autogen-agentchat`, not AG2.
</Aside>

## Release timeline

- **1.2.x (October 2026)** — current line. Additive: A2A servers on several replicas, push-notification URL validation and input media-type checks, `reasoning` option on `OpenAIResponsesConfig`, Firecrawl and Keenable search toolkits, Mistral live/speech configs, plus provider and knowledge-store fixes. No changes needed to 1.1 code on this site.
- **1.1.x (September–October 2026)** — patch releases on top of 1.0.
- **1.0.0 (27 July 2026)** — the protocol-driven framework (previously previewed as `autogen.beta` from 0.11.4 to 0.14) becomes the top-level `ag2` package. Classic agent classes, `GroupChat`, swarms and the `autogen` import name are removed from `ag2`; Classic continues in the [ag2ai/ag2-classic](https://github.com/ag2ai/ag2-classic) repository.
- **0.14.0 (June 2026)** — last `ag2` release with the Classic `autogen.*` API; the swarm API (`autogen.agentchat.contrib.swarm_agent`) was removed.
- **0.11–0.13 (February–June 2026)** — from 0.11.4 (March), an `autogen.beta` event-driven preview alongside the Classic API, which still included swarms (`autogen.agentchat.contrib.swarm_agent`).

## Install, minimal example

```python
import asyncio

from ag2 import Agent
from ag2.config import OpenAIConfig

agent = Agent(
    "assistant",
    prompt="You are a helpful assistant.",
    config=OpenAIConfig(model="%%model=openai-small%%"),  # reads OPENAI_API_KEY
)


async def main() -> None:
    reply = await agent.ask("Hello!")
    print(reply.body)


asyncio.run(main())
```
