**AG2 is the community continuation of AutoGen** (the fork led by AutoGen's original authors in late 2024). With **AG2 1.0 (July 2026)** the project replaced its AutoGen-era API: `pip install ag2` now gives you an async, protocol-driven framework imported as `ag2`, built around `Agent`, `@tool`, typed events and a multi-agent **Network**. The old `autogen.*` API lives on as **AG2 Classic**.

<Aside type="caution" title="ag2 1.x is not a drop-in upgrade from 0.x">
  If your code says `import autogen` or `from autogen import ConversableAgent, GroupChat`, you are on **AG2 Classic**. Upgrading to `ag2>=1.0` removes that namespace entirely. Either stay on Classic — published on PyPI as `autogen` (or pin `ag2<1.0`), in maintenance mode with security and critical fixes only, documented at [classic.docs.ag2.ai](https://classic.docs.ag2.ai) — or port to the new API. See [AG2 Classic and migration](./ag2_comprehensive_guide/#ag2-classic-and-migrating-from-0x).
</Aside>

<Aside type="note" title="AG2 is not Microsoft AutoGen">
  Microsoft's own AutoGen (`autogen-agentchat` / `autogen-core`, the 0.4+ actor-model rewrite) is a separate project covered in the [AutoGen guide](/autogen-guide/). Note that the `pyautogen` name on PyPI now installs Microsoft's `autogen-agentchat`, not AG2.
</Aside>

## Release timeline

- **1.1.x (September–October 2026)** — current line; patch releases on top of 1.0.
- **1.0.0 (27 July 2026)** — the protocol-driven framework (previously previewed as `autogen.beta` in 0.11–0.14) becomes the top-level `ag2` package. Classic agent classes, `GroupChat`, swarms and the `autogen` import name are removed from `ag2`; Classic continues in the [ag2ai/ag2-classic](https://github.com/ag2ai/ag2-classic) repository.
- **0.14.0 (June 2026)** — last `ag2` release with the Classic `autogen.*` API.
- **0.11–0.13 (spring 2026)** — `autogen.beta` event-driven preview; swarm functions moved under `autogen.agentchat.contrib.swarm_agent` in 0.13.0.

## Install, minimal example

```python
import asyncio

from ag2 import Agent
from ag2.config import OpenAIConfig

agent = Agent(
    "assistant",
    prompt="You are a helpful assistant.",
    config=OpenAIConfig(model="gpt-4.1-mini"),  # reads OPENAI_API_KEY
)


async def main() -> None:
    reply = await agent.ask("Hello!")
    print(reply.body)


asyncio.run(main())
```
