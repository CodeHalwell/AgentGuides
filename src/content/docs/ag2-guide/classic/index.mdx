**AG2 Classic** is the `import autogen` API (`ConversableAgent`, `GroupChat`, `initiate_chat`) that AG2 inherited from AutoGen 0.2 and shipped in the `ag2` package up to 0.14.0. Since AG2 1.0 (July 2026) it has been maintained separately in [ag2ai/ag2-classic](https://github.com/ag2ai/ag2-classic) and published on PyPI as `autogen`.

</CardGrid>

<Aside type="caution" title="Three packages, three code bases">
  `autogen` (and `ag2<1.0`) installs **AG2 Classic**. `ag2>=1.0` installs the new AG2 framework, which has no `autogen` module. `pyautogen` now installs **Microsoft AutoGen** (`autogen-agentchat`), a separate, archived project covered in the [AutoGen guide](/autogen-guide/). Pin explicitly.
</Aside>

Classic receives security and critical fixes only. Upstream documentation is at [classic.docs.ag2.ai](https://classic.docs.ag2.ai).

## Minimal example

```python
from autogen import ConversableAgent, LLMConfig

llm_config = LLMConfig({"api_type": "openai", "model": "%%model=openai-small%%"})   # reads OPENAI_API_KEY

assistant = ConversableAgent("assistant", system_message="You are a helpful assistant.", llm_config=llm_config)
user = ConversableAgent("user", human_input_mode="NEVER", llm_config=False)

result = user.initiate_chat(assistant, message="What is 2 + 2?", max_turns=1)
print(result.summary)
```
